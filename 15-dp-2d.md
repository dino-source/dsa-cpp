# LeetCode Pattern: Dynamic Programming (2D)

## Overview

The Dynamic Programming (2D) pattern is used when a problem depends on
two changing dimensions instead of one.

The main idea is to define a state using two variables, such as:

- two indices;
- two strings;
- row and column;
- item and capacity.

Instead of recomputing the same subproblems:

```text
Brute force:
Explore the same states repeatedly.

Dynamic programming:
Store answers for each state and reuse them.
```

2D Dynamic Programming is commonly used for:

- string comparison;
- grid problems;
- edit operations;
- subsequences;
- knapsack-style problems.

The most common steps are:

1. Define the DP state.
2. Find the transition.
3. Initialize the base cases.
4. Fill the DP table.

In C++, this pattern commonly uses:

- `std::vector<std::vector<int>>`;
- 2D arrays;
- rolling arrays for space optimization.

The key skill is recognizing when a solution depends on two independent
variables.

## Pattern Recognition Checklist

Ask yourself:

- Does the answer depend on two changing variables?
- Am I comparing two strings or sequences?
- Am I moving through a grid?
- Can I define a state using two indices?
- Are there overlapping subproblems involving two dimensions?

If yes, 2D Dynamic Programming is likely a strong candidate.

## Common Dynamic Programming Variations

### Grid DP

Each cell depends on neighboring cells.

Example:

```text
dp[row][col]
```

Typical examples:

- Unique Paths
- Minimum Path Sum

---

### String DP

Each state represents prefixes of two strings.

Example:

```text
dp[i][j]
```

Typical examples:

- Longest Common Subsequence
- Edit Distance
- Regular Expression Matching

---

### Knapsack DP

Each state depends on the current item and the remaining capacity or sum.

Example:

```text
dp[item][capacity]
```

Typical examples:

- Partition Equal Subset Sum
- Target Sum

---

### Interval DP

Each state represents a range.

Example:

```text
dp[left][right]
```

Solve larger intervals using solutions to smaller intervals.

Typical examples:

- Burst Balloons

---

## Space Optimization

Many 2D DP problems only depend on the previous row.

Instead of storing the entire table:

```text
dp[rows][cols]
```

Store only the rows that are still needed:

```text
previous_row
current_row
```

This can reduce:

- Space complexity: `O(rows × cols)`

to:

- Space complexity: `O(cols)`

---

## Complexity

Most 2D Dynamic Programming solutions have:

- Time complexity: `O(rows × cols)`

or

- Time complexity: `O(n²)`

Space complexity is typically:

- `O(rows × cols)`

Many problems can be optimized to:

- `O(cols)`

using rolling arrays.
